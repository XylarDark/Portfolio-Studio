# Public vs private content

This repository is **public** and deploys to GitHub Pages from `main`
(https://xylardark.github.io/Portfolio-Studio/). Anything on `main` can appear
on the live site.

Keep only generic, public-safe portfolio material here:

- Luke Thompson’s general resume (`public/resumes/luke-thompson.pdf` and `.html`)
- The game-developer resume (`public/resumes/luke-thompson-gamedev.pdf`)
- The public portfolio at `/u/admin/portfolio`

Company-specific pitch pages, tailored resumes, cover letters, and application
notes (including salary asks and personal answers) live in the private repo
[XylarDark/Application-Packs](https://github.com/XylarDark/Application-Packs).
Do not add them back to this repo.
