# Portfolio Studio

Simple elegant media-resume site for creative work — film, photography, and motion.

## Stack

- Vite
- React 19
- TypeScript

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Customize

Edit sample work and resume entries in `src/data.ts`, and update copy in `src/App.tsx`.

Sample photography in `public/media/` is from [Pexels](https://www.pexels.com/) for placeholder use.
